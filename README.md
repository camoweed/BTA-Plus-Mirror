## BTA! Plus Modpack

**If you would like your mod removed from this pack contact** ``camoweed@betarecobbled.net`` **or** ``@camoweed`` **on discord.**


For clarity *NO BINARIES ARE PACKAGED* with BTA! Plus.zip itself.
Instead, when the game is launched it will compare the file hash of index.toml, and downloads **only** from official sources.
Downloads prioritize Modrinth, then Git, then local hosting (locally only with permission of author).

BTA! Plus is possible due to the efforts of many talented modders, so I will take the time to thank them each.
